# ben-ten-aliens-force

Web prototype of a third-person Ben 10-inspired action game built with Babylon.js.

## Current prototype

- Mobile joystick and touch camera
- Omnitrix selection menu
- Ben
- Heatblast / Пламенный
- Humungousaur / Гумангозавр
- Echo Echo / Эхо Эхо
- Unique movement stats and attacks
- Simple enemy AI and combat
- GitHub Pages deployment

Live demo: https://oartemios.github.io/ben-ten-aliens-force/

## Structure

- `index.html` — entry point and Babylon.js loader
- `src/game.js` — scene and gameplay loop
- `src/aliens.js` — alien definitions and temporary models
- `src/input.js` — desktop/mobile controls
- `src/omnitrix.js` — Omnitrix selection UI
- `src/styles.css` — UI styles

The primitive models are placeholders. Real GLB models and animation will be added later.
